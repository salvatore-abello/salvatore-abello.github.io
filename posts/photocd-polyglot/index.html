ELF in the Pixels: Building Shared Object/Image Polyglots

Posted on 2026-04-27 14:40:32 • 488 words • 3 minute read
Tags: Cybersec, Research, server-side, Writeup, Python, Polyglot

In this post, I will talk about how to build Shared Object/Image polyglots that lets you bypass image checks in python. I’ll start by introducing one of the challenges I wrote for TRX CTF 2026 that uses this trick to achieve RCE on a python web application.

Index

Why this post exists?

I was inspired by a challenge I solved a while back, IMGC0NV from HITCON CTF 2025, which involved creating a pickle/image polyglot. In that challenge, a BMP polyglot was used so that PIL would process the file as an image, while the same bytes could later be interpreted as a malicious pickle stream and deserialized through Python’s multiprocessing IPC to achieve RCE.

As far as I know, this specific .so/image polyglot technique has not been used elsewhere before, and it could come in handy in scenarios where you need to bypass image validation to “smuggle” shared object files.

Challenge Overview

We’re given an image-hosting service written with python and FastAPI. We’re allowed to upload custom images, which are validated by the processing.is_valid_image function:

from PIL import Image as PILImage, ExifTags

# ...

def is_valid_image(data):
    try:
        im = PILImage.open(io.BytesIO(data))
        im.verify()

        return True
    except Exception:
        return False

So is_valid_image tries to identify the image format and parse its header and checks that the file is structurally valid.
